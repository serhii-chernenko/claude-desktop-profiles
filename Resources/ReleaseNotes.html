Claude Profiles 0.1.4

  • Claude Profiles now checks for a new version each time it opens, not only once a day counted from the last check.
  • When an update was downloaded automatically, Setup & Settings, the app menu and About show Restart to Install with the new version, so you can install it right away instead of it waiting silently for the next quit.
  • Update the command-line tool under Setup & Settings so the auto-rebuild agent uses this version.
