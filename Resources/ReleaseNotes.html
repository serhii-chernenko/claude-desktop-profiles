Claude Profiles 0.1.2

  • When a rebuild, recolor or re-sign changes a profile's signature, its macOS privacy permissions are reset. Grants that no longer match the app are cleared, so a Files & Folders switch (for example access to Google Chrome's data) no longer turns itself off.
  • New Reset Permissions… on the profile page (and claude-profiles reset-permissions) for profiles that are already affected.
  • The Keychain prompt for "Claude Safe Storage" after each rebuild is now explained correctly: a self-signed certificate has no Apple Team ID, so macOS asks once for every new build. Enter your login keychain password and click Always Allow.
  • Update the command-line tool under Setup & Settings so the auto-rebuild agent uses this version.
