Claude Profiles 0.1.1

  • Releases are now signed with a stable certificate instead of ad-hoc. macOS keeps the Accessibility permission across updates instead of silently dropping it.
  • Check for Claude Updates asks macOS for the Accessibility permission itself, so Claude Profiles shows up in the list again after it was removed.
  • The permission is named the way macOS 27 shows it: Device Control and Data Access. There is also a fix for when the switch is already on but the permission does not work.
