Claude Profiles 0.1.9

  • New Storage window (menu Clean Up Storage…, or Storage… on a profile's page) shows everything each profile keeps on disk, with sizes, biggest first, in four tabs: Overview, Worktrees, Caches and History.
  • Worktrees: pick the Code tab's git worktrees to remove by age (7, 14, 30, 60 or 90 days) or one by one. A removed worktree's branch goes with it when all its commits are saved elsewhere; branches with unsaved commits stay unless you switch on Delete branch for that row.
  • Caches: clear rebuildable app caches and older Claude Code versions. The Cowork VM disk is listed too, but only removed when you select it.
  • History: delete the Claude Code conversation history of chosen projects for good.
  • The same is available in the terminal: claude-profiles storage, worktrees, caches and history, with a live progress line, size tables and --dry-run. Sizes are measured in parallel, about three times faster.
