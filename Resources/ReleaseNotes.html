Claude Profiles 0.1.3

  • Removing a profile now also clears its macOS privacy permissions, so its Claude <Name> entries no longer stay behind in System Settings > Privacy & Security.
  • New claude-profiles prune-permissions clears entries that profiles removed earlier left behind. Run it once from a terminal that has Full Disk Access; after that, removing a profile and the auto-rebuild agent clean up by themselves whenever they can read the privacy database.
  • Claude's own permissions and those of profiles that still exist are never touched.
  • Update the command-line tool under Setup & Settings so the auto-rebuild agent uses this version.
